# 本批在原始③规划中的位置

依据：`results/planning/plan.html` 的“C1．从局部边缘解析得到整体排液的边界交换”。
当前结果以本分支代码、原始记录和结果页为准；规划中的历史状态不是最新进度。

| 原规划需要回答的问题 | 当前证据与未完成项 |
| --- | --- |
| 能否让运动膜与解析边缘共享液量、表活和功？ | 已有含切向自由度的曲面面积／单层表活原生原型；接口账本和保存步机械公式可核对。固定化学势浴液仍是本微算例的外边界，尚非独立预测的整体边界处理。 |
| 夹缩、局部通量是否收敛？ | 实际时间配对、布局敏感性和本次全域加密正在分开检查。已有空间失败保留；不能用几何恒等式、单个膜厚值或短窗口替代动态空间收敛。 |
| 独立物理法向通量和牵引力能否支持接口功？ | 已有独立SI压力梯度／速度切面恢复，但它是不相容重建，仍有差异。离散功恒等式不等于连续物理牵引力验证。 |
| 局部解能否预测交换系数、薄膜元厚度比？ | 尚未实现这两个独立预测。不会把文献交换系数作为输入后再宣称预测了它，也不拟合条纹指数选择速率。 |
| 是否存在可用的局部—整体尺度分离及成本优势？ | 尚未证明。当前保留动态边缘状态；只有误差和时间尺度证据支持时，才考虑较便宜的边界算子。不能先强加无记忆通量律。 |
| 能否解释整体条纹，并在保留几何／材料中预测？ | 主实验、保留工况及整体条纹定量验证未完成。这个无重力、无分离压的不溶性短时释放算例不能替代它们。 |

本次10微秒试算检验的是实际全域分辨率基础，并测量继续计算的成本。
原10、50、200微秒检查点没有缩减；即使首个点通过，也不是完整C1。
发现空间差异后，优先判断分辨率／离散问题与物理通量，而不是用更多
相似的几何恒等式积累“通过数”，或把通用Voronoi方法当成新的排液物理。

C2仅在独立物理与时间尺度依据支持时引入；本批没有新增交换速率、
人工形状校正力或用于制造目标排液规律的参数。
