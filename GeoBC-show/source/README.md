# Source snapshots

CAD example: install numpy and gmsh, then run `python tools/build_rod_v2_cad.py --output rod-example`. Other files are review snapshots of the calculation pipeline, not a standalone simulation package. Full reproduction requires the native mesh, assembled loads, constraints, material contract and environment. Large raw inputs are not included in this showcase. The current FEn implementation only supports the source-matched virgin elastic branch and stops at yielding.
