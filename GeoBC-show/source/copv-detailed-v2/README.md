# COPV C01 detailed construction concept v2

18 independent positive-volume CAD solids: Al 6061 metallic liner, 0.15 mm epoxy bondline, four 0.75 mm carbon/epoxy structural ply groups (+55/-55/-55/+55 degrees), two tapered polar reinforcement collars, two Ti-6Al-4V boss bodies with embedded flanges and turned grooves, two hollow 316L port inserts with wrench hexagons, four elastomer O-rings, and two PEEK backup rings. The upper insert is longer and has a different bore from the lower service insert. Ports are metallic, clearly distinct from carbon/epoxy.

Body reference dimensions remain R100/L400/D60/b15/neck20/liner1/wrap3 mm. The adhesive and local reinforcement add geometric thickness. Port geometry and material identities are explicit concept choices; this is not a manufacturer's design or a pressure-qualified seal system. Titanium/aluminum/steel compatibility, actual elastomer grade, thread standard, contact/preload and end resultants require design decisions. There are no unsupported internal ribs in the gas cavity.

Each displayed part is tessellated from its actual OCC solid. The section viewer is generated by a real CAD quarter cut and retains solid cut faces. The outer winding and metal machining textures are procedural WebGL shading. The thread texture is a helical visual cue, NOT an exact CAD thread solid or a thread specification. Layer directions are an illustrative layup, NOT a validated winding path.

Reproduce with Python, numpy and Gmsh 4.15.2, from this folder:
```
python -m tools.build_copv_detailed_assembly --output detailed-output
```
This writes complete STEP/BREP, full and section display payloads, and a part/material manifest. The downloadable package contains full STEP/BREP and exact source; the live viewer serves the display payloads separately. All 18 volumes are positive, and STEP round-trip volume differences are recorded in the manifest with a 1e-4 tolerance. These checks do not establish mesh convergence, seal integrity or product qualification.

IMPORTANT: the previous GPU-FEniCSx smoke result is ONLY for the v1 two-layer, open-neck, isotropic simplified geometry. No new FEM result has been calculated for this detailed boss/seal/ply assembly. The old 15 geometry variants and FE report remain accessible as v1 history.
