R05: twenty different accepted full-load geometry/load combinations.
High-response weighted, stratified random selection; not a uniform random sample.
Seed: 2147848923
All twenty geometry IDs differ and do not overlap the previous twenty-image gallery. Nine load families are represented; a family can occur on different geometries.
All ten original targets were accepted, ending at load factor 1.0. Images use true deformation x1, the same camera/physical scale and 0-1000 MPa stress scale.
Surface colors use reference-volume weighted nodal averaging of element four-Gauss-point maxima. Labels/table report the original unaveraged Gauss-point peak.
U/L normalizes maximum displacement by geometry center distance. PEEQ is accumulated equivalent plastic strain.
Comparison changes both geometry and loading; it is descriptive, not a controlled single-factor experiment. Equilibrium is not stability; no new stability certification is implied.
No FE case was recomputed for this visual comparison.
