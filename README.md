# Baiming Zhang · GeoBC research site

The `GeoBC-show/` directory contains the public research log and stable task pages published with GitHub Pages.

## Task-page presentation rule

Task pages are visual-first review pages, not dashboards embedded inside dashboards.

- The top of a task page should contain one primary image or interactive model, followed by only a few short review comments.
- Do not embed a second copy of the task page or a full numeric dashboard in the hero area.
- Put dense metrics, sample counts, parameter tables, QC matrices, timings, download links, and full review history at the end of the page inside the collapsed “查看详情” section.
- Keep the primary visual scientifically traceable. Captions must distinguish display choices—such as deformation magnification or stress averaging—from the underlying computed values.
- Preserve a stable URL for every task and keep incomplete or rejected results explicit in the detailed record.

For the file layout and update sources, see [`GeoBC-show/README.md`](GeoBC-show/README.md).
